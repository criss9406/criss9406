### 👨‍💻 Sobre mí

Me cansé de ver equipos altamente cualificados desperdiciar horas valiosas atrapados en hojas de cálculo en lugar de hacer el trabajo real. 
Hoy, construyo **sistemas de automatización robustos** (usando Python y arquitecturas web ligeras) que eliminan procesos manuales mortales en flujos industriales: cotizaciones lentas, reportes semanales manuales, gestión reactiva de inventarios y errores de precios.

*   **Mi filosofía técnica:** Cero suscripciones pesadas, cero ataduras a proveedores engorrosos (Vendor lock-in), y cero necesidad de tener un departamento de IT para operar mis soluciones. Sistemas ágiles, localizados y 100% enfocados en el valor.
*   **Mi objetivo:** Si tu equipo pasa más tiempo en las tareas de administración que generando impacto real, yo traduzco la operación a código para devolvértelo.

### 🌟 Proyectos Destacados

#### 🏥 [Demo Clínica Web - Sistema de Gestión Cero-Dependencias](https://github.com/tu-usuario-aqui/demo_clinica)
Un ecosistema completo de gestión diseñado para correr "Out of the Box" (sin servidores costosos ni bases de datos complejas). 
* Consta de un motor **FastAPI** asíncrono sobre Python.
* **Arquitectura "Database-less":** Todo el registro transaccional es digerido y orquestado directamente en memoria hacia un fichero local `.xlsx`, para que la administración o los médicos nunca pierdan el acceso físico a su información pura.
* **Integración asíncrona:** Generador en tiempo real de reportes de historiales, boletas unificadas en formato PDF y alertas por correo automatizadas usando hilos (`threading`) cuando los umbrales de inventario son quebrantados u ocurren procesos críticos.
* Resuelve de forma radical la pesadilla de licencias costosas para gestionar micro/medianas clínicas.
